## 프로젝트 이름 : woo.gpt.ai-best

##소개
이 프로젝트는 금융권 데이터 분석 취업을 위해 연관있는 다양한 산업 도메인(FSD, CSS, BI 등)의 복잡한 데이터를 자세하게 분석하고 직관적인 시각화 파이프라인을 구축하기 위한 연구 및 포트폴리오 프로젝트입니다. 캐글(Kaggle) 등에서 확보한 실제 금융권, 의료, 사용자 행동 데이터를 활용하여 데이터 전처리부터 모델링, 시각적 인사이트 도출까지 복합적인 데이터 분석 워크플로를 설계하는것이 목적입니다. 단순한 기술 학습을 넘어 비전공자나 경영진의 합리적인 의사결정을 지원할 수 있는 고부가가치 데이터 결과물을 도출하는 것을 목표로 합니다.

## 주요 기능
이 프로젝트의 주요 기능은 학부 연구생 과정에서 깊이 있게 탐구한 차원 축소 알고리즘과 최신 머신러닝 기법을 실제 데이터에 적용하고 검증하는 데 초점이 맞춰져 있습니다. 가장 핵심적인 부분은 UMAP과 t-SNE를 활용한 고차원 데이터의 차원 축소 및 시각화로 다차원 데이터의 복잡한 구조를 효과적으로 2D/3D 공간에 매핑하고 HDBSCAN과 같은 밀도 기반 알고리즘을 적용하여 숨겨진 패턴과 군집의 안정성을 심층적으로 분석합니다. 또한 시간의 흐름에 따라 변동성이 큰 데이터를 다루기 위해 LSTM 기반의 시계열 분석을 수행하며 RIVER 라이브러리를 도입하여 지속적으로 유입되는 스트리밍 데이터에 모델이 실시간으로 적응하는 온라인/점진적 학습 파이프라인을 구축합니다. 이와 더불어 연구의 질을 높이기 위해 대형언어모델(LLM)을 접목하여 복잡한 데이터 분석 결과를 요약 및 검토하고 분석 과정에서 도출된 인사이트와 트러블슈팅 내역을 옵시디언(Obsidian)을 통해 체계적인 지식 베이스로 문서화하는 기능까지 포괄적으로 구현할 예정입니다.
